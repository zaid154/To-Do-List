## 🌟 Key Features

- ➕ **Add & Delete Tasks**: Quick task entry and removal.
- ✔️ **Toggle Completion**: Strike-through animation for completed items.
- 💾 **Local Persistence**: Saves todo items in the browser's `localStorage`.
- 📱 **Responsive & Clean**: Minimalist aesthetic with high readability.
